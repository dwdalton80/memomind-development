# Star Finder — phone half

Works out which stars are above you and streams their positions to the
glasses. Pairs with [`plugins/glass/star_finder`](../../glass/star_finder),
which owns head tracking and the on-lens guidance; **the design notes and the
wire protocol live in that README.**

```sh
./mm build star-finder   # -> build/web/star-finder.mmpkg
./mm test sky            # the coordinate conversion
./mm studio star-finder  # Browser Studio (Bridge only, no .gmp)
```

## What it does

1. Asks for your location once (`location.foreground`), falling back to
   coordinates you type. The fallback is not only for a denied permission:
   Browser Studio returns a fixed simulated position (Shanghai), Desktop
   Studio may not serve the location Bridge at all, and the sky is unusable
   indoors — so manual entry is what makes the app testable. A location that
   works is remembered through `storage` when that is granted.
2. Converts the catalog's J2000 right ascension and declination into altitude
   and azimuth for here and now — see `sky.js`.
3. Chooses two alignment references and pushes them, plus your selected
   target, down channel `0x0F01` every four seconds. Re-sending is what makes
   the link self-healing: a dropped message costs one interval, not a stall.
4. Renders whatever the glasses report back on channel `0x0F02`.

## Files

| File | Contents |
| --- | --- |
| `plugin.js` | Bridge wiring, messaging, and the UI |
| `sky.js` | Equatorial → horizontal conversion and alignment-pair choice |
| `catalog.js` | 66 bright stars, generated; J2000 in decimal degrees |

`vendor/gm-plugin-web-sdk.esm.js` is generated by `./mm build`.

## Verified in Browser Studio

`./mm studio star-finder` runs the phone half against a simulated Bridge. At
31.230 N, 121.474 E on 2026-09-22 23:09 local it listed 23 stars above the
horizon and put Vega at WNW 33 degrees, against 32.6 degrees altitude and
298.8 degrees azimuth computed independently from the catalog. Fomalhaut sat
at hour angle 0.4 h due south, which is where it belongs on that date.

Browser Studio does not execute the `.gmp`, so the pairing itself is still
only exercised by `./mm sim star_finder` on the glasses side.

## Accuracy

Roughly an arcminute. Refraction, nutation, and proper motion are all
omitted deliberately — each is far below what gyro-integrated heading can
hold, so correcting for them would be false precision.

Stars only, for now. The Moon and planets need ephemerides rather than fixed
coordinates, which is a different and much larger piece of work.
