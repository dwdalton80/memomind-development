# hello-page

MemoMind Web plugin (`com.memomind.hello-page`).

```sh
./mm studio hello-page     # run in PhoneSDK Browser Studio
./mm build hello-page      # package to build/web/hello-page.mmpkg
```

`vendor/gm-plugin-web-sdk.esm.js` is generated by `./mm build` and is not
committed. Declare every Bridge method you call in `manifest.json`.
